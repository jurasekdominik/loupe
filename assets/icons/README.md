# Loupe icon

The vector master `loupe.svg` and Windows icon `../../src/Loupe/loupe.ico` are copied unchanged from the supplied icon pack, which is no longer kept in the repo.

The ICO contains size-specific artwork at 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256 px. The executable and window/tray resources use that single ICO.
